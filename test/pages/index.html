passfox test pages

Mock login pages for checking passfox by eye in Firefox. Nothing you type is kept: the server throws posted forms away.

Before you start

  • These pages run on localhost, so the dropdown only has something to show once you have an entry under localhost/ in your login folder. The quickest way is to use Basic login once and click Save in the doorhanger.
  • That writes to your real store. Remove the test entries afterwards with pass rm -r on localhost and auth.localhost in your login folder.
  • To compare with the real thing, save the same login in Firefox's own password manager (or turn passfox off) and open the same page.
  1. Basic login: username and password, normal form post
  2. Identifier first: username on one step, password on the next
  3. Script login: form added by script, sign-in handled without navigation
  4. Change password: current, new and confirm fields
  5. Sign-up: new-password fields that should not get the dropdown
  6. Edge positions: field near the bottom, inside a scroll box, narrow field
  7. Hostile styles: page CSS that tries to break the popup
  8. Login in an iframe: form served from auth.localhost
  9. Two-step verification: one-time code fields, including one box per digit

What to check

  • Clicking into either field opens the dropdown under it, as wide as the field (at least 250px).
  • Rows show the username and "From this website"; hovering shows the edit pencil.
  • ↓/↑ move a rounded accent ring, Enter fills both fields with the yellow highlight, Esc closes.
  • Typing in the username field filters rows by prefix; typing a password hides the dropdown.
  • Submitting a new login shows "Save password for localhost?" at the top left, and it is still there on the welcome page after the redirect.
  • Submitting a saved username with a different password shows "Update password for localhost?".

    Password store

    Each login is one entry in your password store, named with this pattern: {url} is the website and {username} the username. For example:

    • {url}/{username} → example.com/alex@email.com
    • www/{url}/{username} → www/example.com/alex@email.com
    • {username}@{url} → alex@email.com@example.com
    • www/{url} → www/example.com, one login per website, with the username on its login: line

    Folders before {url} (like www) are where passfox works: entries elsewhere in your store are left alone.

    Firefox’s own “Ask to save passwords” is turned off while passfox is installed, so you’re only asked once. Passwords are saved to pass, with pass’s settings.

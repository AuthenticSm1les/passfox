    Password store

    passfox reads and saves logins inside this folder (for example www for www/github.com/alice). Entries elsewhere in your store are left alone. Leave it empty to use the whole store.

    How login entries are named inside that folder, with {site} for the website and {username} for the username:

    • {site}/{username} → github.com/alice
    • {username}@{site} → alice@github.com
    • {site} → github.com, one login per website, with the username on its login: line

    Firefox’s own “Ask to save passwords” is turned off while passfox is installed, so you’re only asked once. Passwords are saved to pass, with pass’s settings.

    Password store

    A folder in your password store, like www: passfox recognises logins in any layout inside it and saves new ones as <website>/<username>:

    • www/github.com/alice, www/alice@github.com, www/github.com (username on its login: line)

    Or an exact pattern, with {url} for the website and {username} for the username:

    • {url}/{username} → example.com/alex@email.com
    • www/{url}/{username} → www/example.com/alex@email.com
    • {username}@{url} → alex@email.com@example.com
    • www/{url} → www/example.com, one login per website

    Entries outside the folder (before {url}) are left alone.

    Firefox’s own “Ask to save passwords” is turned off while passfox is installed, so you’re only asked once. Passwords are saved to pass, with pass’s settings.
